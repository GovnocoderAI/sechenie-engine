# Стереометрия — сечения, фигуры, доказательства

Онлайн-версия: https://govnocoderai.github.io/sechenie-engine/

## Запуск локально

```bash
python serve.py
```

По умолчанию раздаётся `index.html` из корня репозитория. Если файл называется иначе:

```bash
python serve.py -f stereo.html -p 8000
```

Полезные флаги: `--no-open`, `--quiet`, `--qr`, `--tunnel`, `--firewall`.

## Что умеет

- Строит сечения многогранников методом следов, параллельных прямых и перпендикуляров.
- Показывает пошаговое доказательство и измерения: площадь, периметр, объёмы частей.
- Конструктор тел: призмы, пирамиды, усечённые пирамиды, бипирамиды, антипризмы.
- Платоновы тела: правильный тетраэдр, куб, октаэдр, додекаэдр, икосаэдр.
- Параметрические призмы, пирамиды и усечённые пирамиды с основанием 3–12.
- Параллельный перенос и зеркальная симметрия: применить к телу или построить выпуклую оболочку копии.
- Генератор заданий с уровнями сложности и серией из пяти задач.

## Файлы

- `index.html` — приложение (HTML/CSS/JS без сборки).
- `serve.py` — локальный сервер и туннели.
